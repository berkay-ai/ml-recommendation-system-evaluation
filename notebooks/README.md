## Notebooks

This folder contains the final notebook used for building and evaluating the recommendation system.

The notebook includes:

- Data preprocessing and sampling
- Model training using TruncatedSVD
- Temporal validation to simulate real-world conditions
- Evaluation using Precision@10 and Recall@10
- Error analysis, including zero-hit rate evaluation

The goal of this notebook is to provide a reproducible and structured pipeline for analyzing model performance and identifying limitations in recommendation systems.
